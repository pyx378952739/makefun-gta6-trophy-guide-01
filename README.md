Leonida Ledger — an offline GTA 6 trophy guide and tracker for PlayStation 5: all 55 official trophies with a guide for each in our own words, a checklist saved in your browser, a platinum roadmap in seven phases, missable trophies flagged with their windows, next-up recommendations, search and filters, and a spoiler setting that hides story trophies until earned. No network needed, no account, no ads.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

Or open `app/index.html` directly in a browser — it is plain static files.

## What is inside

- `app/` — the guide itself: `index.html`, `app.js`, `style.css`, `data/trophies.json`
- `screenshots/` — 4 captures of the running app (1280×800, first is the cover)
- `shots.json` — what each screenshot shows
- `main.ts` — hands the app and screenshots to `/output` with a `dossier.json` (`MAKEFUN_OUTPUT_DIR=out node main.ts` to try it locally)
- `serve.ts` — tiny static server for local use

## Sources & honesty

Names, descriptions and grades come from the official PS5 trophy list on Exophase (frozen 2026-11-18), cross-checked against PSNProfiles. No PSN rarity counts are shown: none had been verified when this guide was written, and no numbers are invented here. The guides are our own words, written from the official descriptions alone; GTA 6 released 2026-11-19 and the guides have not been checked in the game, so any step or location not pinned down by the official description is marked unverified in the guide itself. Not affiliated with Rockstar Games.
